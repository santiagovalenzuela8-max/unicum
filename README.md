# Rapporti Giardiniere

App web (un solo file, `index.html`, nessuna installazione) per creare e inviare alle aziende i rapporti dei lavori di giardinaggio.

## Uso
Apri `index.html` nel browser (anche da telefono).

1. **Impostazioni** – inserisci i tuoi dati e personalizza l'elenco dei lavori (taglio prato, potatura siepi, concimazione, ecc.).
2. **Aziende** – aggiungi le aziende clienti con email e WhatsApp.
3. **Nuovo rapporto** – scegli azienda, data/orari, spunta i lavori fatti, aggiungi materiali, note e foto.
4. **Invia** – via Email, WhatsApp, Condividi (con foto, da telefono) oppure Stampa / PDF.

I dati restano salvati nel browser (localStorage); nessun server.
